# GCD Calculator 🔢

## What It Does

Finds the Greatest Common Divisor (GCD) also called HCF of two numbers.

## Logic Used

- Take two numbers as input
- Find all divisors of both numbers
- Identify the largest common divisor
- Used Euclid's algorithm approach

## Example

Input: `48` and `18` → Output: `6`

## What I Learned

- Finding divisors using modulo operator
- Comparing two sets of divisors
- Optimizing with Euclid's algorithm

## Challenges Faced

- Understanding the relationship between GCD and remainders
- Handling cases where one number divides the other completely
