# Vowel Counter 🔤

## What It Does

Counts vowels in a string and shows which vowels appeared.

## Logic Used

- Remove spaces and convert string to lowercase
- Loop through each character
- Check if character is a vowel (a, e, i, o, u)
- Store each vowel found in a list and count them

## Example

Input: `"manav"` → Output: `['a', 'a']` and `"There is 2 vowels"`

## What I Learned

- String methods: `.replace()` and `.lower()`
- Checking membership with `in` operator
- Building lists dynamically
