# Prime Number Finder (1 to 100)

A simple Python program that finds and displays all prime numbers between 1 and 100.

## Description

This program identifies prime numbers in the range from 1 to 100 using an optimized primality testing algorithm. It's great for beginners learning about:
- Prime numbers
- Loops and conditionals in Python
- Basic algorithmic optimization

## What are Prime Numbers?

Prime numbers are natural numbers greater than 1 that have no positive divisors other than 1 and themselves. For example:
- 2, 3, 5, 7, 11 are primes
- 4, 6, 8, 9, 10 are not primes (composite numbers)

## Features

- ✅ Checks numbers from 1 to 100
- ✅ Uses square root optimization for efficiency
- ✅ Returns results as a clean, formatted list
- ✅ Includes both a function-based and one-liner implementation
