# LCM Calculator 📐

## What It Does

Finds the Least Common Multiple (LCM) of two numbers.

## Logic Used

- Find multiples of the larger number
- Check which multiple is divisible by the smaller number
- First match is the LCM

## Example

Input: `12` and `18` → Output: `36`

## What I Learned

- Finding multiples using loops
- Checking divisibility with modulo
- LCM is always ≥ the larger number

## Challenges Faced

- Finding an efficient way without GCD formula
- Knowing when to stop the loop (when multiple is found)
