# Second Largest Finder 🥈

## What It Does

Finds the second largest number in a list without using `sort()` or `max()`.

## Logic Used

- Initialize two variables as negative infinity
- Loop through the list once
- Update largest and second largest based on comparisons
- Skip duplicates when updating second largest

## Example

Input: `[1, 4, 6, 3, 8, 9, 2]` → Output: `8`

## What I Learned

- Using `float('-inf')` for initialization
- Single-pass algorithm
- Handling duplicate values in lists
